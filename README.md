# 🍎 Apple Homepage Clone

A responsive frontend recreation of the Apple homepage, built as a web development practice project.

## 📌 About The Project

This project is a frontend recreation inspired by the official Apple homepage.

The goal of this project was to practice creating a clean, modern, responsive website layout while improving my skills in **HTML and CSS**.

Official website used as design reference: [Apple.com](https://www.apple.com/?utm_source=chatgpt.com)

## ✨ Features

* Responsive homepage layout
* Apple-inspired navigation bar
* Product showcase sections
* Responsive images
* Modern typography and spacing
* Clean and minimal UI
* Desktop and mobile responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Web Design

## 📚 What I Learned

While building this project, I practiced:

* Semantic HTML structure
* CSS Flexbox
* Responsive layouts
* Image positioning
* Spacing and typography
* Recreating real-world website layouts
* Organizing frontend project files
